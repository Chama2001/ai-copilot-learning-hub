# Prompt Engineering Cheat Sheet

Master the art of communicating effectively with AI models.

## 🔑 Key Components of a Good Prompt
1. **Persona/Role:** Tell the AI who it should act as (e.g., *"Act as an expert Python developer"*).
2. **Context:** Provide background information about the problem.
3. **Task:** Clearly state what you want the AI to do.
4. **Constraints:** Set boundaries (e.g., *"Keep the response under 200 words"*).
5. **Output Format:** Specify how you want the result (e.g., *"Provide the answer in a markdown table"*).

## 🚀 Example Prompt Structure
> "Act as a Senior Software Engineer. Review the following Python Flask function for security vulnerabilities, explain any issues found, and rewrite the secure version using best practices."
