# Contributing to AI & Copilot Learning Resources Hub

First off, thank you for taking the time to contribute! 🎉 

## How Can I Contribute?
1. **Reporting Bugs:** Open an issue if you notice broken links or outdated resources.
2. **Adding Resources:** Submit a Pull Request (PR) with new tutorials, guides, or prompt templates.
3. **Improving Documentation:** Fix typos or clarify existing guides.

## Pull Request Process
1. Fork the repo and create your branch from `main`.
2. Ensure your markdown files are properly formatted.
3. Open a Pull Request with a clear description of your changes.
