# Starter Templates & Boilerplates

Ready-to-use starter projects and boilerplates to jumpstart your AI application development.

## 📂 Available Templates
1. **[Python Flask AI Backend](./python-flask/)** - A lightweight backend template integrated with AI APIs and error handling.
2. **[Next.js & React Frontend](./nextjs-react/)** - A modern full-stack UI template styled with Tailwind CSS for AI web apps.

## 🚀 How to Use
Choose a template folder, clone or download it, and follow the instructions in its respective `README.md` to run it locally.
